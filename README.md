## 先分清楚：你要租的是「面板服」還是「遊戲雲 VPS」

這是新手最容易買錯的一步。

**遊戲雲 VPS** 是一台 KVM 虛擬機，有完整作業系統（Windows 或 Linux），你可以遠端連進去，像操作一台電腦那樣裝 Java、放服務端、改設定檔、同時開好幾個程序。自由度最高，但環境要自己弄。雨云的遊戲雲 VPS 全系列配 NVMe 固態硬碟、30+20G 硬碟空間，下行頻寬最高 200M，可自定義開放 15 個連接埠。

**面板服**則是把服務端跑在 Docker 容器裡，用 MCSManager（MCSM）或雨云自研面板管理，全程網頁操作，一鍵開服。不用碰指令列，環境別人幫你裝好，代價是彈性較小——官方說明是一台面板服只跑一個 Docker 容器，可用官方提供的映像檔類型有限，但對 Minecraft Java 版與基岩版相容性沒問題，其他 Java 程式也能跑。

## 固定計費與動態計費：差別在 CPU 使用率

雨云的遊戲雲產品同時支援固定計費與動態計費，這也是它跟多數同價位服務商比較不一樣的地方。

固定計費就是傳統月租，價格固定，用多少都一樣。動態計費則是「低月租 + CPU 超額日結」：官方設計的基準是 CPU 使用率 20%，低於 20% 不計為耗電，超過的部分才逐日結算，官方把這筆費用稱作 CPU 電量。記憶體與其他硬體不產生電量費用。

怎麼選其實不難。每天固定開兩小時以上、玩家會長時間掛在線上的伺服器，固定計費比較穩，帳單一眼看得出來。只是週末跟朋友玩幾小時、平常放著不開的，動態計費的低月租優勢才發揮得出來——伺服器閒置時 CPU 使用率低，那幾天幾乎不產生額外費用。

面板服還多一種選擇：按天計費，當天不開機就不收費，資料保留 30 天。對於「寒暑假才開服」這種使用模式，這比月租划算得多。

## 高防、線路與延遲：台灣玩家要留意的部分

遊戲服的痛點不是流量，是被打。一個公開 IP 的 Minecraft 伺服器，被掃到之後挨 DDoS 是常態。雨云遊戲雲全系列搭 BGP 高防網路，多數機型是共享高防，如果想要獨享防護，可以另外加購獨立公網 IP。

另一個常被誤解的地方是**連接埠**。不少遊戲雲機型走 NAT 模式，也就是多人共用一個公網 IP，靠連接埠映射對外開放，官方允許自定義開放 15 個連接埠。這對單一 Minecraft 服務端完全夠用（25565 一個就夠），但如果你要一次開好幾個服務端給不同群組玩，就得先算清楚埠夠不夠，或者直接加購獨立 IP。

## 常見問題

**租伺服器跟自己架主機差在哪？**
自己的主機要同時負擔遊戲運算與對外連線，還要處理 IP 曝光、防火牆、斷電、動態 IP 等問題。租用是把這些交給機房，換來穩定的上行頻寬與高防，代價是每月固定支出。

**面板服能不能裝模組或整合包？**
可以。官方說明面板服支援上傳自己的服務端與整合包，也支援 MySQL、計劃任務與備份功能。至於要跑哪個映像檔類型，下單前確認一下你的服務端屬於哪一類比較保險。

**人數不多，是不是買最低階就好？**
最低階跑原版生存幾個人在線沒問題，但如果你的整合包動輒上百個模組，瓶頸會先出現在記憶體上。官方標示 200+ 模組整合包在入門級只能承載 1 人，這就是提醒：模組服不要照著人數買配置。

**可以先買一個月試試嗎？**
可以，月付是基本選項，加上 7 天無理由退訂與 1 元試用，前期幾乎沒有什麼風險。真正的成本風險來自「一次買一年但後來不玩了」。

**伺服器要對外公開營運，有什麼要注意的？**
公開聯機涉及所在地的法規與實名規範，這部分不是服務商能替你處理的，開服前自己確認清楚。
